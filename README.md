# EventEase — Event Coordination Platform

EventEase is a full-stack event scheduling and coordination platform originally developed in a **private team repository** as part of a collaborative software engineering project.

This repository is a **public mirror of my contributions** to that project so my engineering work can be reviewed and evaluated publicly.

I was a **core contributor** on the system and owned key backend and integration components, including:

- Google Calendar **OAuth 2.0** integration  
- **Flask REST API** design and implementation  
- **MongoDB** data models and JWT-based authentication  
- Calendar sync and **email notification** pipelines  
- Deployment and environment configuration  

The platform allows groups of users to vote on availability, ranks time slots using aggregated preference scoring, and automatically creates calendar events for all participants.

- **Frontend:** React  
- **Integrations:** Google Calendar API, SMTP Email  
- **Deployment:** Docker, CI/CD, Vercel
